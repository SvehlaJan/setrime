# Telegram Expense Bot

A Telegram bot that parses expenses from banking app screenshots or free-form text messages and logs them to a Google Sheet for monthly spending tracking.

## Status: Research & Planning

See [PLANNING.md](./PLANNING.md) for the full research document covering:

- Telegram Bot frameworks comparison
- OCR / image parsing approaches
- LLM options with cost-value analysis
- Google Sheets integration methods
- Hosting options (self-hosted vs cloud)
- Proposed architecture and data model
- Security considerations
- Open questions before implementation
